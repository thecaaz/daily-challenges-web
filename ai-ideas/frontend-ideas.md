# Frontend Feature Ideas

Notes: Frontend ideas focused on UX, discoverability, performance and real-time features.

- Improved Game Discovery
  - Description: Add tag-based filtering, difficulty filters, and "trending" sorting on the home and games pages.
  - Impact: High. Effort: Medium.

- Personalized Feed / Recommendations
  - Description: Dashboard recommendations based on past plays, favorites, and friends' activity (collaborative/behavioral signals).
  - Impact: High. Effort: Large.

- Dark Mode & Theme Sync
  - Description: Persistent theme toggle, follow OS preference, and optionally sync across devices for logged-in users.
  - Impact: Medium. Effort: Small.

- Progressive Web App (PWA)
  - Description: Make the site installable with offline-cached leaderboards and basic pages for mobile users.
  - Impact: High (mobile reach). Effort: Medium.

- Real-time Live Scoreboard (SignalR/WebSocket)
  - Description: Push live submission updates to clients for active games or tournaments using SignalR.
  - Impact: High for engagement. Effort: Medium.

- Compact / Power-user UI Mode
  - Description: Keyboard shortcuts, denser lists, and keyboard-driven submission flows for fast workflows.
  - Impact: Low–Medium. Effort: Small.

Suggested next steps:
- Prioritize top 2 frontend items for a UI spike and design mockups.
- Open issues for accessibility and responsive improvements.
