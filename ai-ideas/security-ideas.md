# Security & Privacy Ideas

Notes: User safety, compliance, and data lifecycle.

- Two-Factor Authentication
  - Description: Optional 2FA for account security (TOTP, SMS, and backup codes).
  - Impact: Medium. Effort: Medium.

- GDPR & Data Export/Delete
  - Description: Endpoints to export or delete user data, including associated uploads.
  - Impact: High. Effort: Medium.

- Storage Retention Policies
  - Description: Configurable retention and automatic purge for old screenshots and large blobs.
  - Impact: High. Effort: Small.

Suggested next steps:
- Add user data export/delete endpoints and document admin retention policies.
- Review storage and backup plans for compliance.
